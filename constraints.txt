# requirements.txt includes this file with `-c constraints.txt`, so the floors
# apply to normal installs and to the dependency audit gate.
#
# These are not direct dependencies, so they don't belong in requirements.txt;
# a constraints file holds a patched floor without adding them as top-level pins.
# A constraint is inert until something in the resolution actually pulls the
# package in, e.g. python-multipart only once python-fasthtml is added.
